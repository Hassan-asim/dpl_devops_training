## Learning Path Quick Reference

### Phase 1: Foundations (Week 1-2)
**Topics:** Linux Essentials, VirtualBox, SSH, File Permissions
**Resources:** Linux Essentials YouTube tutorial
**Hands-on:** Set up Ubuntu and Amazon Linux 2 VMs

### Phase 2: Web Technologies (Week 2-3)
**Topics:** Nginx, Git Workflows, TypeScript Fundamentals
**Resources:** Nginx course, Git tutorial, TypeScript documentation
**Hands-on:** Configure Nginx, create Git workflows

### Phase 3: Cloud Fundamentals (Week 3-4)
**Topics:** AWS Cloud, EC2, S3, RDS, Route53
**Resources:** AWS Cloud Practitioner course, AWS Skill Builder labs
**Hands-on:** Launch EC2, create S3 bucket, deploy website

### Phase 4: Intermediate AWS (Week 4-7)
**Topics:** IAM, CloudFormation, VPC, Auto Scaling
**Resources:** AWS documentation, official CDK guide
**Hands-on:** Create CloudFormation templates, VPC design

### Phase 5: Advanced Architecture (Week 7-8)
**Topics:** AWS CDK, CI/CD Pipelines, ECS/Fargate
**Resources:** AWS CDK guide, CodePipeline documentation
**Hands-on:** Deploy CDK stacks, build CI/CD pipelines

### Phase 6: Production Implementation (Week 8-9)
**Topics:** Full-Stack Architecture, HA, DR, Cost Optimization
**Resources:** Well-Architected Framework, AWS best practices
**Hands-on:** Deploy complete 3-tier production system
