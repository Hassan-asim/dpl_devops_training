 # Claude Review Demo - Research & Development

## Overview
This repository is a **research and prototype project** for integrating **Claude AI** (Anthropic) into a GitLab CI/CD workflow. The goal was to **explore and understand automated AI-based code reviews** in a merge request pipeline.

> ⚠️ This is a **demo/research project**. Full API execution requires Anthropic credits, which are not available in this environment.

---

## Research Goals
- Understand how Claude AI can perform automated code review.
- Explore GitLab CI/CD pipelines and runners for AI integration.
- Investigate environment variables and secrets management for API keys.
- Test the feasibility of automated review jobs in a merge-request workflow.

---

## Repository Structure
claude-review-demo/
├─ claude_review.py # Python script to call Claude API for reviews
├─ .gitlab-ci.yml # GitLab CI/CD configuration
├─ README.md # Project documentation (this file)
└─ ... # Other files used for testing/demo


---

## CI/CD Setup & Pipeline

- **Runner:** `Claude AI Review Runner` (shell runner on Windows)
- **Pipeline Stage:** `review`
- **Job Steps:**
  1. Upgrade pip and install `anthropic`.
  2. Fetch latest code from `main`.
  3. Execute `claude_review.py` for AI code review.
- **Trigger:** Only runs for merge requests (`$CI_PIPELINE_SOURCE == "merge_request_event"`).
- **Environment Variables:**
  - `ANTHROPIC_API_KEY` stored as a **protected & masked** GitLab CI/CD variable.

---

## Testing & Demo Actions

1. Registered a **GitLab shell runner** on Windows.
2. Installed dependencies and verified PowerShell (`pwsh`) availability.
3. Committed and pushed `.gitlab-ci.yml` and `claude_review.py`.
4. Triggered merge request pipelines to see job execution.
5. Ran `claude_review.py` locally to test API calls and confirm environment setup.
6. Observed pipeline behavior:
   - Dependencies installed successfully.
   - Git fetch/checkout works.
   - Jobs fail if `ANTHROPIC_API_KEY` is missing or API credits are zero.

---

## Observations & Limitations

- **API Access:** CI/CD jobs fail with:Your credit balance is too low to access the Anthropic API.

- **Model Deprecation:** `claude-3-7-sonnet-latest` triggers a deprecation warning.
- **Runner Issues:** Initial shell runner failed due to missing PowerShell (`pwsh`), resolved by installing and adding to PATH.
- **Local vs CI/CD:** Full AI review requires a valid API key and credits; currently the pipeline can only simulate the workflow.

---

## Summary

This project demonstrates a **research-driven approach** to integrating AI review in CI/CD. While actual API calls cannot run due to credit limitations, the pipelines, runner configuration, and testing scripts validate the workflow logic and provide a solid foundation for future implementation.

> This README, along with the repository, serves as a **research report and demo documentation**.
