HOW THE ENVIRONMENT VARIABLES WORK
The Flow:

/etc/environment (on EC2 server)
|
| source /etc/environment (in start_server.sh)
|
| nohup env VAR1=$VAR1 VAR2=$VAR2 (passes to dotnet)
|
| Program.cs loads builder.Configuration
|
| Services inject IConfiguration
|
| Developer accesses via config["VARIABLE_NAME"]

Access Methods Available to Developer:

METHOD 1 (RECOMMENDED):
constructor(IConfiguration config)
{
var aiFunctionName = config["AI_EXAMINATION_FUNCTION_NAME"];
}

METHOD 2:
var aiFunctionName = Environment.GetEnvironmentVariable("AI_EXAMINATION_FUNCTION_NAME");
